# index*ac* Table Usage and Mapper Mapping

This document summarizes what data is used from `index_ac_*` tables and where that data is mapped in the workorder mappers.

Runtime query usage is in:

- `src/lib/db/queries/find-workorders.sql`
- `src/lib/db/queries/get-workorders.sql`

## Notes

- Activity fields such as `wsa_id`, `activity_status`, `activitysequencenumber`, `activityrequiredflag`, `workbasketname`, and `assigned_to` are mapped in `src/lib/db/mappers/to-activity.js`, but they come from `ahwork_ac` and `pr_operators`, not from `index_ac_*` tables.
- Duplicates in activities, facilities, and livestock units are deduplicated in `src/lib/db/mappers/to-workorders.js`.
